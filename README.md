# AutoZone - Auto Parts & Accessories (WD-EC-006)

This repository contains the complete frontend web application for the **AutoZone Auto Parts & Accessories** e-commerce project developed as part of the **Data Alcott Systems Free Web Development Internship Online**.

## Project Overview
AutoZone is an online store offering engine components, brakes, tires, lighting, and accessories. 

## Task Details
- **Task ID:** WD-EC-006
- **Student Code:** DAS-EC-006
- **Internship Type:** Free Web Development Internship Online
- **Company:** Data Alcott Systems ([www.dataalcott.com](https://www.dataalcott.com))

## Features Implemented
- **Home Page & Categories:** Navigation, banner, category cards (Engine Parts, Brakes & Tires, Lighting, Accessories).
- **Product Catalog & Search:** Grid display with live search bar and category filtering.
- **Shopping Cart:** Add items, quantity adjustment, subtotal, tax, and total calculation.
- **Checkout Process:** Shipping address and payment method handling.
- **User Account:** Simulated user profile and order history.
- **About & Contact:** Company story, mission, and interactive contact form.

## Technologies Used
- HTML5, CSS3, JavaScript (Vanilla JS, No Database Required).
